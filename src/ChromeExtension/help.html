Tab Bridge 導入・接続の確認

この手順はオフラインでも読めます。Managerと拡張は常時接続していません。表示されるIDは、この拡張を開いたChromeプロファイルのものです。

1. 拡張を導入する

Chrome Web Storeでの正式配布は準備中です。現在のGitHub版ZIPは開発・試用向けです。展開したフォルダーを移動せずに保管し、chrome://extensions のデベロッパーモードから「パッケージ化されていない拡張機能を読み込む」で、manifest.jsonがあるフォルダーを選びます。ZIPのまま読み込むことはできません。

2. 同じプロファイルのIDを設定する

  1. 使いたいタブグループがあるChromeプロファイルで、この拡張を有効にします。
  2. 拡張のポップアップで「IDをコピー」を押します。コピーできない場合はID欄を選択してCtrl+Cを押します。旧版は上部の32文字の拡張ID、またはchrome://extensionsに表示されるIDをコピーします。
  3. Managerの「設定」の「拡張機能ID」に貼り付け、「候補に保存」を押します。Chrome実行ファイルと、開いたプロファイルも確認します。
  4. 名前を付けたタブグループを開き、Managerに同じグループ名の項目を作成します。候補と競合を確認してから「変更を反映」します。候補の保存だけではWindowsに反映されません。

3. 段階を分けて確認する

  • ポップアップのグループ一覧に対象があるか確認し、「開く」で移動できるか試します。一覧は現在のプロファイルに開いているグループだけです。
  • Managerから対象項目をテストします。失敗時はID、Chromeのパス、プロファイル、グループ名を確認します。拡張が無効・未導入のプロファイルには接続できません。
  • 最後にManagerを閉じ、Windowsの実際のHotKeyで確認します。テスト起動の成功だけではHotKey登録の成功は確認できません。

更新・IDが変わった場合

開発版は同じフォルダー内のファイルを更新し、chrome://extensionsで「再読み込み」します。Managerと拡張のバージョンを確認してください。別フォルダーや将来のStore版へ移るとIDが変わる場合があります。先にManagerのバックアップを取り、新しいIDを設定し、変更内容を確認して適用・再テストしてください。古い拡張を先に削除しないでください。

保存情報と権限

tabGroupsはグループの一覧・開閉、tabsは対象タブへの移動と復帰補助、storageは設定・復帰履歴、notificationsは操作失敗の通知に使います。Webサイトの内容を読み取るスクリプトやホスト権限はありません。

設定と最大100グループの復帰履歴（グループ名、タブID、任意のURL、記録時刻）はこのプロファイルのローカル領域に保存し、外部送信・同期しません。ポップアップの「保存する情報と履歴の管理」からURL保存の停止と履歴の消去ができます。拡張を削除すると拡張の保存情報は削除されます。Manager側の設定やWindowsショートカットは別に残ります。
