# v0.4.0 — v1.0.0準備の開発版スナップショット

所有者の依頼により開発を区切って使用環境へ反映する版です。v1.0.0の正式品質・全環境検証の完了を宣言するものではありません。確定後は本作業を停止し、[残作業一覧](v1.0.0-remaining-after-v0.4.0.md)へ引き継ぎます。

## 主な変更

- Apply/Restore・バックアップ保持・異常終了復旧・未知の設定形式の保護を強化。管理外リンクや編集されたファイルを勝手に整理しない方針を維持。
- 保存済みと編集候補、監査と修復、Explorer反映と実HotKey確認を区別。復元差分・バックアップ履歴・直前Applyを戻す導線を追加。
- 編集項目・キー選択・競合/不足の説明、元lnk参照、起動前プレビュー、URI/作業フォルダの案内を改善。
- Chrome拡張のIDコピー・オフライン導入手順、復帰履歴のURL保存停止/削除、失敗時の応答と診断情報を整備。
- 個人のパス/URL/名前/ログ原文を既定で含めない診断を、内容確認後に新規ファイルへ保存可能に。
- 小画面スクロール、モニター/DPI別のサイズ制限、Altアクセスキー、読み上げ名と結果通知、Windowsコントラスト配色への追従を改善。主操作hoverの白文字/薄背景を修正。
- Setup更新の保持検証、不要になった所有ファイルの退避、SPDX/ビルド元記録・GitHub署名来歴・固定したビルドツールと更新監視を追加。

Managerは非常駐、Windowsの.lnk HotKeyを使います。外部BAT、Chrome Dispatcher、拡張の権限・Protocol v1、設定schema 1を維持します。

## 更新と戻し方

1. 未保存の編集を整理してManagerを閉じ、設定/状態/バックアップ/管理リンク、旧版Setupと拡張ファイルを保全します。
2. 公開checksumに一致する`ShortcutManager-Setup-win-x64-v0.4.0.exe`で更新します。開発ビルドを製品フォルダへ直接コピーしません。
3. 既存のunpacked拡張は同じ保存先へ中断復旧付きの更新手順で配置し、Chromeで再読み込みして実行versionとIDを確認します。別のIDへ自動移行しません。
4. 設定・管理リンクのbyte保持と起動監査を確認します。監査やファイル一致は、物理HotKeyの再確認とは別です。
5. 問題がある場合は保全した旧版Setup/拡張・バックアップを使って復旧します。設定versionを手書きで下げたり、管理外ファイルを消したりしないでください。

所有者環境への実際の更新結果は[公開後記録](POST_RELEASE.md)へ追記します。タグ/公開物は記録修正のために上書きしません。

## 残る制限

- EXE/Setupは未署名です。署名証明書/サービス契約と、内部Setup/Uninstallを含む実署名が未完了です。
- Chrome Web Storeは未公開。GitHub ZIPは開発・試用向けで、正式導入URL/アカウント/審査の工程が残ります。
- 実際のNarrator・OSコントラストテーマ全画面、JIS/US/IME、混在DPI/複数モニター/標準ユーザーの代表操作は未完了です。非表示描画やfixtureを実機完了と扱いません。
- 安全な管理外HotKey解除GUI、特殊lnkの代表実機条件、任意の完全削除UI、非技術者ユーザーテスト等が残ります。

検証の詳細は[VERIFICATION](../verification/VERIFICATION.md)、対象/未検証の区別は[環境マトリクス](../verification/ENVIRONMENT_MATRIX.md)、全残件は[残作業一覧](v1.0.0-remaining-after-v0.4.0.md)を参照してください。
