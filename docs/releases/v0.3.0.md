# Shortcut Manager v0.3.0

HotKeyの起動遅延を調べる機能と、Chrome連携の安定化をまとめた更新です。設定schemaとDispatcher Protocol v1は維持します。

## 改善

- #115: 「起動診断」から、Shellの起動待ちに関係し得る応答のないウィンドウを確認できます。常駐・自動終了・外部送信はありません。
- #47: 拡張の通信・設定保存に失敗した場合も、理由と再試行の導線を表示。応答不明時に勝手に再実行しません。
- #48: Popupで同名のグループが複数あっても、選んだ行のウィンドウを正確に開きます。
- #84: 一括折りたたみの成功・失敗・消滅件数を分けて表示。
- #85: 複数グループのタブ履歴を同時更新しても失わないよう直列化。
- #86: Chrome起動直後の自動折りたたみが、明示的な開閉を上書きしないよう調整。Worker停止・復帰にも対応。

## 起動が遅い場合

同じリンクの直接実行は速く、HotKeyだけが数秒遅い場合、対象アプリを起動する前にWindows Shellが別アプリの応答を待っている可能性があります。「起動診断」の候補は原因の断定ではありません。作業を保存して通常終了し、キーの反応と再診断を比較してください。製品は他アプリを強制終了しません。

所有者実機の隔離リンク試験では、承認を得て応答のない2アプリを終了した後、実キーから対象コード到達までの中央値が約3.09秒から約0.14秒に改善しました（各10回）。これは環境側の待ち時間の解消であり、新バージョンだけで全アプリを高速化する保証ではありません。詳細・計測精度は検証記録を参照してください。

## 更新手順・互換性

Chrome拡張を先にv0.3.0へ更新・再読み込みし、Managerを終了してSetupを実行してください。配置先とExtension ID、既存のキー割り当てを維持します。旧focus-groupと現行toggle-groupは継続対応します。Popupの新しい実体指定メッセージは同梱Workerと組み合わせます。

Windows EXE/Setupは未署名です。従来のWindows x64・Chrome/unpacked配布範囲を維持し、閉じた保存グループの復元や常駐updaterは含みません。
