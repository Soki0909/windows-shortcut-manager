# v1.0.0までの残作業 — v0.4.0確定時点

2026-11-03。所有者の依頼によりv0.4.0を使用環境へ反映して、本作業を停止する。v1.0.0は未完了。下記は未解決Issue 42件の引継ぎであり、実装済み部分も受け入れ条件全体が未完了なら残している。#155は本版で修正しPR #156のmain統合で完了。#1は全体索引。公開後の確認結果は[更新記録](post-release/v0.4.0.md)を参照。

## 正式版に向けた優先残作業

- **配布の信頼**: #50 / #140 — 証明書または署名サービスの準備、EXE/Setup/内部コピー/Uninstallの実署名とtimestamp検証。実署名は未実施。
- **Chrome正式導入**: #46 — アカウント確認、掲載用の実画面、提出/審査/正式URL、公開IDへの移行確認。説明/権限/プライバシー原稿は準備済み。
- **表示・入力・支援技術**: #19 / #20 / #21 / #54 — 実OSのコントラスト/Narrator、JIS/US/IME、DPI/複数モニター/標準ユーザーの代表操作、サポート範囲とSetup制約の整合。基礎実装/描画/Peer検査だけでは完了にしない。
- **再現可能なGUI検証**: #55 — 初回導入・編集・監査・反映の一連操作をGUI回帰へ。実Appの配色回帰は追加したが、全フローは未完了。
- **移行・削除の安全性**: #31 / #32 / #52 — 管理外HotKey解除GUIとrollback、特殊lnkの代表条件、保持説明に加えた任意の完全削除UI/設計。
- **一般利用者向けの仕上げ**: #11 / #12 / #14 / #15 — 用語統一、画像/動画の導入案内、非技術者テスト、操作の配置の評価。
- **実Chrome起動条件**: #118 — runtime.onStartupの受信から起動時折りたたみまでを専用環境で確認。profile/ID診断や失敗画面の改善は#87/#88にも残る。
- **CIの安定性**: #157 — Release CIで発見したUNC fixtureのSMB共有後片付け失敗を診断する。再実行の成功と原因解消は区別する。
- **最終リリース判定**: 上記の必要条件を完了/採否判断し、1.0.0の版・互換性・署名・最終配布検証・公開物の独立照合・使用環境更新/rollback証拠を揃える。
