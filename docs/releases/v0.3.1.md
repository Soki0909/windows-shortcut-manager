# Shortcut Manager v0.3.1

変更反映とバックアップ復元の確実性を改善する更新です。既存のキー割り当て、設定schema、Dispatcher Protocol v1、非常駐方式は維持します。

- #64: 作成直後と配置後のショートカットを、起動時監査と共通の全属性で読み戻して照合します。不一致なら以前の状態へ戻します。
- #62: Explorer再起動の取消・終了待ち時間切れ・復帰失敗にも、独立した制限時間でShell復旧を試みます。復旧確認とHotKey反映成功は区別し、失敗時は手動起動手順を示します。
- #65: 復元件数、復元前バックアップ、Explorerへの反映待ちを画面に残します。復元後も同意を得てExplorer再起動へ案内し、辞退・失敗時には反映待ちを保持します。
- #66: 保存・復元時にバックアップ範囲を説明し、不足する外部BATや参照lnkのパスを復元前に確認できます。

バックアップは保存済み設定・管理リンク・反映状態を含みます。外部BAT/CMD、参照元lnk、アプリ本体、Chrome拡張の設定、タブの内容、未適用の編集は含みません。外部ファイルを移動した場合は元の場所へ戻すか、参照先を修正してバックアップを作り直してください。不足がある復元は現在の状態を変更せず停止します。

旧Managerを終了し、Setupで更新してください。Chrome拡張はバージョンを揃えたv0.3.1を提供します（動作コードはv0.3.0と同一）。既存フォルダを更新して再読み込みする場合はExtension IDを保持してください。Windows EXE/Setupは従来どおり未署名です。
