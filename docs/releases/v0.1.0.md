# Shortcut Manager v0.1.0

Windowsの `Ctrl+Alt+A–Z` を、Website・アプリ・BAT/CMD・Chromeタブグループへ割り当てる非常駐の管理アプリです。

## インストール

`ShortcutManager-Setup-win-x64-v0.1.0.exe` をダウンロードして実行してください。ユーザー単位でインストールされ、管理者権限や別途.NET Runtimeの導入は不要です。インストール後はスタートメニューの「Shortcut Manager」から起動できます。

既存ユーザーの設定・バックアップは引き継ぎます。アンインストール時も設定と管理HotKeyを保持します。フォルダを展開して使いたい場合はportable ZIPを利用できます。

## 主な機能

- Website / Application / BAT・CMD / Chrome Tab Groupの登録、編集、テスト起動
- モダンなWPF UIと物理キー配列順の `QWERTYUIOP / ASDFGHJKL / ZXCVBNM` 表示
- 起動時の実ショートカット監査と、バックアップ付き自動修復
- Apply後の確認付きExplorer再起動で、Windows再起動なしにHotKeyを反映
- 管理外HotKeyの競合検出、既存ショートカットのインポート、バックアップ／復元／ロールバック
- Managerを終了した後もWindowsの `.lnk` HotKeyで動作

Chromeタブグループを使う場合は、TabBridge ZIPを展開して `chrome://extensions` のデベロッパーモードから読み込み、表示されるExtension IDをManagerに設定してください。拡張機能はWindowsインストーラーには含まれません。

## 配布ファイル

- `ShortcutManager-Setup-win-x64-v0.1.0.exe`: 通常インストール用
- `ShortcutManager-win-x64-v0.1.0.zip`: portable版
- `ShortcutManager-TabBridge-v0.1.0.zip`: Chrome拡張機能
- `SHA256SUMS.txt`: 上記3ファイルのSHA-256

## 検証・制限

Core 15件、Windows 20件、Chrome拡張10件のテストが成功。Windows実機でインストール・再インストール・アンインストール・設定保持、起動監査、物理HotKeyの反映と解除を確認済みです。

Windows配布物は未署名です。Chrome Web Store／Microsoft Store公開と自動更新は含みません。Chrome上で閉じている保存済みタブグループの復元は対象外です。起動監査は保存されたショートカットを照合し、ほかの常駐アプリによるキー取得までは列挙できません。
