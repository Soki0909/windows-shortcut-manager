# Shortcut Manager v0.1.1

Windowsアプリとインストーラーに製品ロゴを追加しました（#8）。

- EXE、タイトルバー、タスクバー用Windowアイコン、ヘッダー、Setupへ同じロゴを適用。
- 16 / 24 / 32 / 48 / 64 / 128 / 256pxのICOを収録。
- CIとReleaseで、EXE・Setupに埋め込まれた全サイズのアイコンと成果物チェックサムを検証。

## 更新

`ShortcutManager-Setup-win-x64-v0.1.1.exe` を実行して既存版を更新してください。設定・バックアップ・管理HotKeyを引き継ぎます。portable版は新しいZIPを別フォルダに展開して利用できます。

起動中の旧版は終了し、更新後にスタートメニューから起動してください。タスクバーにピン留めした旧アイコンが残る場合は、更新したアプリをピン留めし直してください。

## 配布ファイル

- `ShortcutManager-Setup-win-x64-v0.1.1.exe`: 通常インストール用
- `ShortcutManager-win-x64-v0.1.1.zip`: portable版
- `ShortcutManager-TabBridge-v0.1.1.zip`: Chrome拡張（機能変更なし、製品バージョンを統一）
- `SHA256SUMS.txt`: 上記3ファイルのSHA-256

Windows配布物は未署名です。Store公開・自動更新は含みません。
