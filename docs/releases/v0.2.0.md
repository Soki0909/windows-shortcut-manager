# Shortcut Manager v0.2.0

Chromeタブグループの開閉と、設定・バックアップ・中断復旧の安全性をまとめた更新です。

## 更新手順

1. Chrome拡張をv0.2.0へ先に更新し、Popupで版とExtension IDを確認します。ZIPを既存のunpacked配置先へ展開してChromeで再読み込みします。配置先やIDを変更した場合はManagerの設定にも反映してください。
2. 開いているManagerを終了し、Setupを実行します。設定・バックアップ・管理HotKeyは保持します。
3. Managerを起動すると既存Chromeリンクを開閉動作へ再生成します。新規・変更キーが反映されないときは、画面の案内に従いExplorerまたはWindowsを再起動してください。

展開済みの対象は、別アプリが前面でも折りたたまれます。折りたたみ状態なら展開し、最後に使ったタブへ戻ります。タブは削除しません。Popupの「開く」と旧リンクは従来どおり開く専用です。

- #2・#4・#5・#6・#7・#37〜#40: 原本保全、復元時競合、管理外ファイル保護、破損設定の復旧モード、設定・ZIP容量/整合性検証、原子的バックアップ保存。
- #3・#63: 書込み前の永続ジャーナルと、異常終了後の復旧。復旧を完了してから起動監査を実施します。手動変更や破損を検出した場合は退避データを残して停止します。
- #34・#35: 版ごとの多重起動防止と、処理中の編集・Apply・Restoreの割込み防止。
- #57: 個人プロファイルを使用しない実Chrome統合回帰。
- #61: ドラフト添付物の再取得・検証・クリーン環境Setup smokeが成功してから公開。
- #92: Manager/拡張の互換表と最低版の案内。Debugの保存先・EXE・表示も製品版から分離。

## 互換性と制限

|Manager|拡張|動作|
|---|---|---|
|0.1.x|0.1.x / 0.2.0|Protocol v1の開く専用|
|0.2.0|0.2.0以降|新リンクの開閉、旧focus-group/Popupの開くも維持|
|0.2.0|0.1.x|Website/App/BATは使用可。Chrome開閉は拡張更新が必要。未対応actionの表示が出たら拡張版を確認|

Managerは導入済み拡張の版を直接取得しません。拡張Popupで確認してください。将来のProtocol不一致・最低版不足は新拡張のDispatcherに理由を表示します。

Windows EXE/Setupは未署名です。署名があると表示していません。Windows x64、Chrome、unpacked導入を対象にした従来の配布範囲です。閉じた保存グループの復元や常駐updaterは含みません。前面条件の調査はP3の#112として継続します。

同じ公開版の添付物は置換しません。公開前の検証が失敗した場合はドラフトを残し、正式公開しません。
