# Shortcut Manager v1.0.0

Windows Shortcut Manager および Shortcut Manager Tab Bridge の v1.0.0 リリースです。

## 主な変更（v0.4.0 からの追加・改善）

- **任意のローカルデータ削除・復旧・アーカイブ復元 (#52)**:
  - 公式アンインストーラーの既定保持（設定・バックアップ・管理リンクを保持）を維持したまま、Manager の「確認と復旧」→「削除の準備・データ削除と復元…」から、解除前バックアップ検証付きの全キー解除、読取り専用プレビュー、削除前アーカイブ作成検証、ジャーナル付き退避・取り消し・確定消去・クラッシュ再開、削除前アーカイブからの復元を行えます。
  - GUI・監査専用起動・CLI の起動時に未完了削除を確認し、退避完了・判断待ち状態での再起動時は確認画面へ復帰します。
- **元ショートカットの手動 HotKey 移行支援 (#31 / #32)**:
  - 起動時監査に元リンクの参照鎖検査を追加し、管理外 `.lnk`/`.url` の原本復旧コピー作成と手動解除・手動復元・再スキャンを案内する GUI を追加しました。
- **Chrome 連携の診断強化 (#87 / #88 / #118)**:
  - Dispatcher 失敗時の表示時間を15秒へ延長し、手動「閉じる」ボタン・ヘルプ導線・同一 Chrome セッション内の直近エラー表示（固定エラーコードと時刻のみ、グループ名や例外生文字列は非保存）を追加しました。
  - 複数 Chrome プロファイル利用時の挙動と公開 API の制約、ID が正しいのに開かない場合の3段階切り分け手順を Manager および拡張ヘルプへ追加しました。
  - 隔離 Chrome での起動時折りたたみ・Worker 停止復帰・セッション保護リセットの実起動検証を追加しました。
- **品質・回帰検証の強化 (#55 / #157 / #172 / #176)**:
  - CLI モード（`--apply-config` / `--restore-backup`）における `ShortcutInventoryScanner.ScanAsync` の UI スレッド同期待機デッドロックを修正しました。
  - 実 WPF イベント経路の隔離 GUI 回帰テスト、UNC 共有フィクスチャの後片付け安定化、Setup 下限（`MinVersion=10.0.14393`）の整理、および公式旧版 Setup からの更新・保持ライフサイクル検証を追加しました。

Manager は非常駐で動作し、Windows の `.lnk` HotKey、外部 BAT/CMD、Chrome Dispatcher URI v1、拡張の権限・Protocol v1、設定 schema 1 を維持します。

## 更新と戻し方

1. 未保存の編集を整理して Manager を閉じ、現在の設定・状態・バックアップ・管理リンク、および旧版（v0.4.0）Setup と拡張ファイルを別フォルダへ保全します。
2. 公開チェックサム（`SHA256SUMS.txt`）および GitHub Build Provenance Attestation を照合した `ShortcutManager-Setup-win-x64-v1.0.0.exe` で更新します。開発ビルドを製品フォルダへ直接コピーしないでください。
3. 既存の unpacked 拡張は同じ保存先へ中断復旧付きの更新手順（`scripts/deploy-unpacked-extension.ps1`）で配置し、Chrome の `chrome://extensions` で再読み込みして実行バージョン（`1.0.0`）と ID を確認します。 [拡張の更新手順](../verification/EXTENSION_UPDATE.md)
4. 設定・管理リンクの保持と起動監査を確認します。物理 HotKey と実 Chrome タブグループ操作は別途確認してください。
5. 問題がある場合は、保全した旧版 Setup・拡張ファイル・バックアップから復旧します。

## 現時点の制限（未実施・外部前提）

- **コード署名 (#50 / #140)**: EXE および Setup は **未署名（NotSigned）** です。GitHub Build Provenance Attestation はビルド来歴の検証であり、Authenticode コード署名の代用ではありません。
- **Chrome Web Store (#46)**: Chrome Web Store への提出・審査・正式公開は未実施です。本リリースの `ShortcutManager-TabBridge-v1.0.0.zip` は GitHub 配布版です。
- **独立検証機・第三者テスト (#12 / #14 / #15 / #19 / #20 / #21 / #54)**: 独立した Windows 11 25H2 x64 検証機の標準ユーザーにおける物理 JIS/US・IME・実 DPI 切替・複数モニター・Narrator/高コントラスト・第三者初回ユーザーテストは未実施です。詳細は [VERIFICATION.md](../verification/VERIFICATION.md) および [ENVIRONMENT_MATRIX.md](../verification/ENVIRONMENT_MATRIX.md) を参照してください。
