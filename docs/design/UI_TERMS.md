# 画面の用語

| 表示 | 意味 |
| --- | --- |
| 割当 | 名前・文字キー・起動先をまとめた1件の設定 |
| 候補に保存 | 編集画面の値をメインの編集候補へ戻す。Windowsへの保存はまだ行わない |
| 未保存の変更 | 保存済み設定と候補の差分。元の値へ戻すと差分から除く |
| 変更を反映 | 自動バックアップ後、保存済み設定と管理リンクを更新する |
| 保存済みを監査 | 保存済み設定とWindowsの管理リンクを比較する。候補の破棄やリンクの修復は行わない |
| 編集を破棄して再読込 | 未保存の候補を破棄して保存済み設定を読み直す |
| テスト起動 | 起動先を実際に開く。アプリ・BAT等では先に解決済みの起動内容を表示する |
| 起動内容のプレビュー | 実行先・実際の引数・作業フォルダを表示する。表示だけでは実行しない |
| Explorerを再起動 | WindowsのHotKey反映を試す。物理キーの動作確認とは別 |
| 実キーの動作確認 | 利用者が実際のキーで動作を確かめたという、今回の起動中だけの申告 |
| 管理リンク | 所有マーカーのある管理フォルダ内で、この製品が生成したWindowsショートカット |
| 作業フォルダ | 起動時のカレントディレクトリ。起動ファイルの保存先とは別に指定できる |
| 拡張機能ID | ChromeのTab Bridgeを識別するa～pの32文字。通常のWebサイト起動には不要 |

基本操作をメインのボタンに、監査・診断・復元等を「確認と復旧」に置く。
必要な入力欄だけを種類に合わせて表示し、任意の引数・作業フォルダ等は詳細にまとめる。
ファイルの絶対パス、URL、URI、グループ名は別の入力として扱う。
.lnk / URI方式の追加引数は現在の起動契約では使わない。既存値は消さず、読み取り専用表示と理由を添える。
