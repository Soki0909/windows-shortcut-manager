# Issue #11 日本語表示の統一

## 受け入れ条件との対応

- [用語集](../design/UI_TERMINOLOGY.md)で一般向けの操作名と詳細情報の用語を定義。オフラインの「使い方」にも「用語」タブを追加した。
- 編集・設定の「候補に保存」、主画面・初回ガイドの「変更を反映」、主画面・初回ガイド・実行前確認の「対象をテスト」を表示専用 `UiText` で共有する。
- 「未保存」は候補の変更に用い、保存後の「反映未確認」とは区別。キー枠と一覧の同じ未保存状態を揃えた。保存値・状態コード・Protocol・ログ書式は変更していない。
- 一覧と編集で種類名を揃え、ショートカットキー、エクスプローラー、拡張メニュー、復旧記録、バージョン等の画面表示を整理した。診断の技術コード、パス、履歴の原文はそのまま扱う。

## 検証

ローカルのbuild/testと、架空の設定だけを使う非表示WPF描画を後続で記録する。実機の一連操作、物理キー、支援技術の確認をこの文言修正の自動検証から推定しない。
